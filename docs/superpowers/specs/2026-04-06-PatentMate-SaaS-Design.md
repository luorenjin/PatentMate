## 1. 产品概述

### 1.1 产品定位

PatentMate 是一款面向企业和个人的专利申请辅助SaaS产品，帮助工程师快速完成技术交底书，并利用AI补全专利申请材料，生成可直接提交或供专利代理人参考的技术文档。

### 1.2 核心价值主张

- **降低门槛**：通过模板+问答方式，帮助技术背景人员轻松撰写交底书
- **提高效率**：AI辅助生成专利文书，减少与代理机构的反复沟通
- **提升通过率**：结构化、规范化的撰写方式，提升专利申请质量

### 1.3 目标用户

- 企业研发工程师
- 个人发明人
- 初创公司IPR（知识产权专员）
- 专利代理机构（辅助工具）

## 3. 用户流程

### 3.1 主流程图

```
┌──────────┐    ┌────────────┐    ┌─────────────┐    ┌──────────────┐    ┌──────────┐
│   登录    │───▶│  选择模式   │───▶│  技术交底   │───▶│  AI 生成     │───▶│  导出    │
│          │    │            │    │  (问答式)   │    │  (分阶段)    │    │          │
└──────────┘    └────────────┘    └─────────────┘    └──────────────┘    └──────────┘
                   │                   │                   │
                   ▼                   ▼                   ▼
            ┌──────────┐        ┌──────────┐        ┌──────────┐
            │完整专利  │        │发明/实用  │        │摘要/权利 │
            │参考材料  │        │新型选择   │        │要求/说明 │
            └──────────┘        └──────────┘        └──────────┘
```

### 3.2 详细步骤

#### Step 1: 认证 (Auth)

- 用户注册（邮箱/手机）
- 登录（密码/验证码）
- 忘记密码
- 首次登录引导（选择角色：个人/企业管理员/团队成员）

#### Step 2: 模式选择

| 模式 | 输出物 | 用途 |
|------|--------|------|
| 完整专利模式 | 摘要、权利要求书、说明书（含实施例）、附图说明 | 直接提交专利局 |
| 参考材料模式 | 技术交底书、发明要点、检索报告草稿 | 提交给专利代理人 |

#### Step 3: 类型选择

| 类型 | 特点 | 核心问题 |
|------|------|----------|
| 发明专利 | 强调技术先进性 | 技术问题→解决方案→技术效果 |
| 实用新型 | 强调产品结构 | 产品形状/构造/结合 |

#### Step 4: 技术交底（智能问答）

**发明专利问题流程：**

1. **技术领域**
   - "请描述您的发明所属的技术领域？"
   - 示例模板："新能源 / 人工智能 / 医疗器械 / ..."

2. **现有技术（背景）**
   - "请描述当前技术中存在的问题或不足？"
   - 提示：可描述现有解决方案及其缺陷

3. **发明目的**
   - "您的发明旨在解决什么问题？"
   - 提示：用一句话概括发明要达成的目标

4. **技术方案**
   - "请详细描述您的技术实现方案？"
   - 提示：包括具体步骤、参数、逻辑关系

5. **核心创新点**
   - "与现有技术相比，您的发明主要创新点是什么？"
   - 提示：列出1-3个关键创新特征

6. **具体实施方式**
   - "请提供1-2个具体实施例？"
   - 提示：可包含优选参数、替代方案

7. **技术效果**
   - "您的发明带来了哪些技术效果？"
   - 提示：效率提升、成本降低、性能改善等

**实用新型专利问题流程：**

1. **技术领域** - 同上
2. **现有产品结构** - 描述现有产品的结构特点及问题
3. **发明目的** - 同上
4. **产品结构描述** - 详细描述产品的形状、构造或结合
5. **技术效果** - 同上

#### Step 5: AI 生成（分阶段确认）

| 阶段 | 输出内容 | 用户操作 |
|------|----------|----------|
| 1 | 摘要生成 | 确认/编辑 |
| 2 | 权利要求书 | 确认/编辑 |
| 3 | 说明书（发明名称、背景、技术方案） | 确认/编辑 |
| 4 | 实施例 | 确认/编辑 |
| 5 | 附图说明 | 确认/编辑 |

**生成模式差异：**

- **完整专利模式**：按上述5阶段完整生成
- **参考材料模式**：生成技术交底书终稿 + 发明要点总结 + 检索关键词建议

#### Step 6: 导出

- **完整专利模式**：导出Word文档（.docx）
- **参考材料模式**：导出PDF/Word

### 4.2 表结构详细设计

#### users 表

```sql
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email TEXT UNIQUE NOT NULL,
  name TEXT,
  avatar_url TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

#### organizations 表

```sql
CREATE TABLE organizations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
   plan TEXT DEFAULT 'free', -- free, basic, pro, enterprise
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

#### team_members 表

```sql
CREATE TABLE team_members (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  organization_id UUID REFERENCES organizations(id),
  role TEXT DEFAULT 'member', -- admin, member, viewer
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  UNIQUE(user_id, organization_id)
);
```

#### patents 表

```sql
CREATE TABLE patents (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  organization_id UUID REFERENCES organizations(id),
  title TEXT,
  type TEXT NOT NULL, -- invention, utility
  mode TEXT NOT NULL, -- full, reference
  status TEXT DEFAULT 'draft', -- draft, drafting, completed, submitted
  disclosure_data JSONB, -- 技术交底数据
  abstract TEXT, -- 摘要
  claims TEXT, -- 权利要求书
  description TEXT, -- 说明书
  embodiments TEXT, -- 实施例
  drawings_desc TEXT, -- 附图说明
  created_by UUID REFERENCES users(id),
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

#### disclosure_templates 表

```sql
CREATE TABLE disclosure_templates (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  type TEXT NOT NULL, -- invention, utility
  category TEXT, -- 技术领域分类
  questions JSONB NOT NULL, -- 问题模板数组
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## 7. AI 生成策略

### 7.1 分阶段Prompt设计

**阶段1: 摘要生成**

```
请根据以下技术交底信息，生成专利摘要（200-300字）：

技术领域：{领域}
发明目的：{目的}
技术方案：{方案}
技术效果：{效果}

要求：
- 包含技术问题、解决方案、技术效果
- 避免使用商业宣传用语
- 语法规范，符合专利局要求
```

**阶段2: 权利要求书**

```
请根据以下信息，生成权利要求书：

发明名称：{名称}
技术方案：{方案}
核心创新点：{创新点}

要求：
- 独立权利要求1个，描述核心技术方案
- 从属权利要求2-4个，描述优选实施方式
- 权利要求清楚、得到说明书支持
```

**阶段3: 说明书**

```
请根据以下信息，生成专利说明书各部分：

背景技术：{背景}
发明目的：{目的}
技术方案：{方案}
具体实施方式：{实施例}

要求：
- 背景技术描述现有技术及其不足
- 发明目的明确要解决的技术问题
- 技术方案详细、清楚
- 实施例充分支持权利要求
```

### 7.2 模型选择

| 场景 | 模型 | 说明 |
|------|------|------|
| 摘要生成 | Gemini 3.0 Flash | 快速、结构化 |
| 权利要求 | Gemini 3.1 Pro | 逻辑严谨 |
| 说明书 | Gemini 3.1 Pro | 内容完整 |
| 实施例 | Gemini 3.0 Flash | 快速生成 |

## 8. 安全与权限

### 8.1 数据安全

- 所有数据传输使用HTTPS
- 密码使用bcrypt加密存储
- Row Level Security (RLS) 策略保护数据访问

### 8.2 权限模型

| 角色 | 功能 |
|------|------|
| 超级管理员 | 管理所有组织 |
| 组织管理员 | 管理组织成员、查看所有专利 |
| 成员 | 创建/编辑自己的专利 |
| 查看者 | 只读访问 |

## 10. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| AI生成质量不稳定 | 用户体验下降 | 分阶段确认，用户可编辑 |
| 数据安全合规 | 法律风险 | 支持自托管，数据本地化 |
| 并发协作冲突 | 数据丢失 | Supabase Realtime + OT算法 |
| 专利法规变化 | 功能失效 | 模块化设计，快速迭代 |
