## Phase 1: 核心质量提升

### ✅ 3.2 权利要求结构化生成 + 校验器 (100%)

**新增文件**:
- `services/claimValidator.ts` - 权利要求结构与格式校验服务

**核心功能**:
1. **格式校验**
   - 检查独立权利要求单句法律文体（禁止句号分割）
   - 验证"其特征在于"标准结构
   - 检查开头规范（"一种"/"一个"）
   - 逻辑完整性检查

2. **引用关系校验**
   - 从属权利要求引用编号提取
   - 引用链完整性验证
   - 引用顺序合法性检查
   - 防止循环引用和跳跃引用

3. **术语一致性初步检查**
   - 识别相似术语变体
   - 提供统一建议

4. **导出函数**:
   ```typescript
   validateClaimStructure(claimsText: string): ValidationResult
   getValidationSummary(result: ValidationResult): string
   ```

**AI Prompt 增强**:
- `services/aiService.ts:generateClaims()`
  - 强制要求单句完整性
  - 明确"一种……，包括……；其特征在于……"结构
  - 从属权利要求必须明确引用编号

### ✅ 3.5 术语一致性检查与禁用词检测 (100%)

**新增文件**:
- `services/terminologyChecker.ts` - 术语一致性检查服务

**核心功能**:
1. **术语提取与分析**
   - 从各章节提取 3-15 字中文词组
   - 统计术语频次和出现位置
   - 识别核心术语（频次 ≥ 3）

2. **术语变体检测**
   - 基于包含关系检测相似术语
   - 基于编辑距离检测拼写变体
   - 生成术语统一建议

3. **禁用词检查**
   - 检测绝对化表述（最佳/完美/彻底解决）
   - 检测过度宣传用语（革命性/颠覆性）
   - 检测绝对化排他表述（唯一/永久）
   - 提供替换建议

4. **导出函数**:
   ```typescript
   checkTerminologyConsistency(patentData: PatentData): TerminologyReport
   fixProhibitedTerms(text: string): string
   ```

**禁用词列表** (已内置):
- 绝对化评价: 最佳/最优/最好 → 优选地
- 绝对化表述: 完美/完全解决 → 有助于解决
- 宣传性用语: 革命性/颠覆性 → 显著改善
- 排他表述: 唯一/绝无仅有 → 具有……特点
- 绝对时间: 永久/永远/始终 → 长期/通常
- 过宽限定: 所有/全部/任何 → 多个/若干/部分
